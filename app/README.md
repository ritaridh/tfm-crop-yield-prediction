# Demo de predicción

La aplicación de demostración se mantiene en un repositorio de despliegue independiente:

https://github.com/ritaridh/tfm-rendimiento-cultivos-demo

Aplicación pública:

https://tfm-rendimiento-cultivos.streamlit.app/

Este repositorio principal conserva los ficheros de configuración utilizados por la demo y el modelo XGBoost compacto. El modelo Random Forest de despliegue permanece en el repositorio específico de la demo debido a limitaciones de transferencia del conector durante esta migración.
