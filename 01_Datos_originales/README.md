# Datos originales

Esta carpeta contiene únicamente los archivos originales de MAPA que son pequeños y necesarios para documentar la construcción del target.

No se almacenan aquí los datos brutos completos de EuroCrops, SoilGrids, ERA5-Land ni Sentinel-2 debido a su tamaño y/o a que se obtienen desde servicios externos.

Consulte `docs/DATA_SOURCES.md` para las fuentes y el procedimiento de obtención.
